Preguntas de análisis

  1. ¿Qué diferencia existe entre input type="text" e input type="email"?
    text permite escribir texto general; email valida que el contenido tenga un formato de correo electrónico.
  2. ¿Para qué se utiliza el atributo name?
    Identifica el dato de cada campo cuando se envía el formulario.
  3. ¿Cuál es la diferencia entre radio y checkbox?
    Radio permite seleccionar una opción dentro de un grupo; checkbox permite marcar o desmarcar opciones de manera independiente.
  4. ¿Qué función cumple required?
    Hace obligatorio completar o seleccionar un campo antes de enviar el formulario.
  5. ¿HTML5 permite almacenar directamente los datos del formulario en una base de datos?
    No. HTML5 crea la estructura del formulario; para guardar datos se necesita un servidor y un sistema de almacenamiento o base de datos.
